package gatewayd // import "github.com/agent-fox-dev/agentkit-go/sandbox/gatewayd"

Package gatewayd is the AgentKit sandbox gateway: a gRPC server that holds
one backend sandbox.Provider and lets authenticated clients (sandbox/gateway)
create, list and destroy sandboxes with it, relaying the Agent protocol to each
sandbox it manages.

Every RPC must carry `authorization: Bearer <token>` matching a configured
token. A sandbox belongs to the token that created it; another token sees it as
an id that does not exist. The server keeps only each token's SHA-256 and logs
only its first 8 hex characters.

It is a separate module so the root and sandbox modules listen on no socket;
the agentkit-gateway command (cmd/agentkit-gateway) serves it over TCP with a
Podman or Docker backend.

FUNCTIONS

func PrincipalFromContext(ctx context.Context) (principal string, ok bool)
    PrincipalFromContext is the principal of the authenticated RPC that ctx
    was made for: in static mode the 64-character lowercase hex SHA-256 of its
    token, in callback mode what the Authenticator returned. A Backend reads it
    in Create, in the Sync of a sandbox that a SyncGit RPC syncs, and in Reap
    when the Gateway.Reap RPC calls it, to learn which caller it serves.

    It reports ok == false on the context of the periodic reap, on the context
    of every Close the server makes on its own, and on any context the server
    did not make. There is no exported way to put a principal on a context.


TYPES

type Authenticator func(ctx context.Context, token string) (principal string, ok bool)
    An Authenticator turns a bearer token into a principal: the identity that
    owns the sandboxes the token creates. It reports ok == false for a token it
    does not accept, and the RPC is then refused with Unauthenticated before any
    request message is read.

    The server calls it once for each RPC, from gRPC's tap handle on the
    connection's I/O goroutine, with a context that carries the peer address
    and the token exactly as presented: the server applies no length or
    character rule of its own to the token. It must be safe for concurrent use
    and must return quickly without blocking, because a slow Authenticator
    stalls every stream on the connection and the server enforces no timeout;
    an embedder whose tokens live in a store keeps an in-memory view of them.
    The server trusts it to compare tokens in constant time.

    A principal is 1 to 256 bytes with no other rule; an empty or longer one
    counts as ok == false. Principals are compared byte for byte, logged as
    given and handed to the backend (see PrincipalFromContext), so a principal
    must not be a secret. A panic is recovered and refuses the RPC; the panic
    value is not logged.

type Config struct {
	// Backend creates the sandboxes. Required.
	Backend sandbox.Provider
	// Tokens are the accepted bearer tokens (static mode): at least one, each
	// at least 32 characters of printable ASCII without whitespace, none
	// repeated. Exactly one of Tokens and Authenticate must be set.
	Tokens []string
	// Authenticate (callback mode) decides which tokens are accepted and names
	// the principal that owns the sandboxes each one creates, in place of
	// Tokens. See Authenticator for what it must do.
	Authenticate Authenticator
	// TLS, when set, serves TLS with it; nil serves plaintext (behind a TLS
	// proxy, or on loopback).
	TLS *tls.Config
	// NetworkModes is the network ceiling: the modes clients may request,
	// intersected with the backend's. Nil means [NetworkNone].
	NetworkModes []sandbox.NetworkMode
	// MaxSandboxes is the most sandboxes held at once; zero means 16.
	MaxSandboxes int
	// MaxTTL is the longest TTL accepted; zero means 24h.
	MaxTTL time.Duration
	// ReapInterval is how often Backend.Reap runs; zero means 10m.
	ReapInterval time.Duration
	// Logger receives one structured line per create, destroy, refused
	// authentication and backend reap; nil discards.
	Logger *slog.Logger
}
    Config configures a Server.

type Server struct {
	// Has unexported fields.
}
    Server is a gateway. Serve it once; Shutdown stops it.

func New(cfg Config) (*Server, error)
    New checks cfg, applies its defaults and returns a Server that is not yet
    serving.

func (s *Server) Serve(l net.Listener) error
    Serve serves the gateway on l until Shutdown: TLS when Config.TLS was set,
    plaintext otherwise, with sandbox.MaxMessageBytes as the message limits and
    every RPC authenticated. It runs Backend.Reap once at start and then every
    ReapInterval; a failed reap is logged, never fatal. It returns nil after
    Shutdown and the listener's error otherwise. Serve is called once.

func (s *Server) Shutdown(ctx context.Context) error
    Shutdown stops the gateway: it stops accepting RPCs, closes every backend
    sandbox it holds (which ends the relayed calls in flight), waits for the
    handlers until ctx is done, and then forces the server to stop. It returns
    the joined Close errors, and nil on later calls.
