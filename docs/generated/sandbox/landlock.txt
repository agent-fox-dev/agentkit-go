package landlock // import "github.com/agent-fox-dev/agentkit-go/sandbox/landlock"

Package landlock is a sandbox provider for Linux hosts whose kernel offers
Landlock ABI 4 (Linux 6.7) or later. It runs agentkit-sandboxd as a child
process of the embedder, over pipes, and the agent's own Landlock ruleset is
the only boundary: a private workspace, HOME and TMPDIR, read and execute on the
system directories, and no TCP under NetworkNone. It needs no container engine,
no image and no privileges.

It is a confinement, not an isolation: it shares the host kernel, memory, CPU
and process table, bounds no resources, and leaves UDP, Unix sockets and signals
unrestricted. Its Capabilities say so. On any other platform, and on an older
kernel, New refuses with ErrNoLandlock and names sandbox/podman, the provider
for untrusted code. The package never confines the embedder's own process.

VARIABLES

var ErrNoLandlock = errors.New("landlock: this host cannot confine a sandbox with Landlock ABI 4")
    ErrNoLandlock: this host cannot confine a sandbox with Landlock ABI 4.
    New wraps it for another platform, an older kernel or a failing probe,
    and Create for an agent whose report falls short; an embedder can fall back
    to sandbox/podman on it.


FUNCTIONS

func New(o Options) (sandbox.Provider, error)
    New returns the provider after checking, in order and stopping at the
    first failure: the platform, the kernel's Landlock ABI (probed once), Root,
    ExtraRO and ExtraRW, and the agent binary and its --version. The version
    check is the only process it starts.


TYPES

type Options struct {
	// Root holds one directory per sandbox. Empty means
	// <os.UserCacheDir()>/agentkit-sandbox-landlock.
	Root string
	// AgentBinary is the agentkit-sandboxd to run. Empty means the file
	// agentkit-sandboxd beside os.Executable(), then the one on PATH.
	AgentBinary string
	// ExtraRO are absolute directories that the agent, and every process a
	// tool starts, may read and execute beneath (--landlock-ro).
	ExtraRO []string
	// ExtraRW are absolute directories they may also write beneath
	// (--landlock-rw).
	ExtraRW []string
}
    Options configures the provider.
