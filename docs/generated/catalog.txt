package catalog // import "github.com/agent-fox-dev/agentkit-go/catalog"

Package catalog embeds AgentKit's Claude model catalog and turns a model id into
the core.Model descriptor of REQ-PROV-10 (Lookup).

The catalog supplies exactly the metadata no provider API returns and no
pass-through can synthesize: context window, output cap, pricing, how the model
takes thinking and its compatibility profile. Every one of those is load-bearing
before the first byte is sent — the max_tokens cap, the cost of a turn and how
thinking is encoded all read it — which is why "just pass the model string
through" is not an option.

The catalog is NOT an allowlist. An id it does not list gets a usable default
descriptor (Lookup), so a model that ships after this snapshot works the day it
ships. All model metadata — prices, token limits, how a model takes thinking —
lives here and nowhere else.

# Layering

catalog imports core and nothing else in the module (plan §1.3). It holds no
mutable package-level state: Default is a sync.OnceValue over the embedded bytes
and every returned core.Model is a deep copy, so a caller who edits a resolved
descriptor cannot corrupt the process-wide catalog.

const (
	ProviderAnthropic  = "anthropic"
	ProviderOpenRouter = "openrouter"
	ProviderOllama     = "ollama"
)
    The providers this build can run. The set is fixed in code, not taken from
    the catalog's vendors: a vendor section that names a provider with no client
    behind it must not be selectable. Each name equals the catalog vendor id of
    the same spelling.

const SchemaVersion = 1
    SchemaVersion is the catalog file format this build understands.

    The catalog is versioned separately from the SDK (REQ-CAT-01), so a
    caller may hand Parse a file newer than this binary. A file that declares
    a different schema_version is rejected rather than parsed on a guess:
    the failure mode of guessing is a silently wrong price or context window,
    which surfaces as a 400 deep into a long session (REQ-CAT-04's stated
    hazard) or as a mis-billed run, and neither is detectable from the result.

const Vendor = "anthropic"
    Vendor is the vendor Lookup resolves against. The catalog lists a vendor for
    each of the other providers too (see Providers).

FUNCTIONS

func Lookup(id string) (core.Model, bool)
    Lookup returns the descriptor for a Claude model id, with or without the
    "anthropic/" prefix, and whether the catalog lists it.

    An id the catalog does not list is not refused: it gets a usable default
    with the requested id, a 1,000,000-token window, a 128,000-token output cap,
    adaptive thinking and no price, so a model released after this snapshot
    works the day it ships.

func Providers() []string
    Providers lists the providers in the order anthropic, openrouter, ollama.
    Every call returns a new slice.


TYPES

type Catalog struct {
	// Has unexported fields.
}
    Catalog is one parsed, validated, immutable model catalog.

    All lookup state is precomputed at Parse time, so resolution is map lookups
    and never a scan. A *Catalog is safe for concurrent use; nothing mutates it
    after Parse returns.

func Default() *Catalog
    Default returns the embedded catalog, parsing it on first use.

    It panics if the embedded catalog is corrupt (REQ-CAT-01 as amended by
    ruling P-15) and panics identically on every later call. It never returns a
    silently empty catalog.

func Parse(data []byte) (*Catalog, error)
    Parse decodes and validates a catalog document (REQ-CAT-01's "overridable
    by the caller"). It is the only constructor; there is no partially-valid
    Catalog, because a catalog that loaded "mostly" is one whose missing row
    becomes a sibling clone with a plausible, wrong context window.

func (c *Catalog) DefaultModelID(vendor string) string
    DefaultModelID is the id of the row REQ-CAT-03 clones for an unknown model
    under this vendor. It returns "" for an unknown vendor.

func (c *Catalog) KnownVendor(id string) bool
    KnownVendor reports whether id names a vendor. This is REQ-CAT-02 rule 1's
    predicate: it decides whether the segment before the first slash of a spec
    is a vendor prefix or just part of an OpenRouter-style model id.

func (c *Catalog) Lookup(id string) (core.Model, bool)
    Lookup is the package-level Lookup against this catalog.

func (c *Catalog) Models(vendor string) []string
    Models lists the model ids of one vendor in sorted order. It returns nil for
    an unknown vendor.

func (c *Catalog) Note() string
    Note is the catalog document's maintenance note, including the REQ-CAT-06
    regeneration ritual.

func (c *Catalog) Select(provider, model string, effort core.Effort) (Selection, error)
    Select turns a provider, a model and an effort into the catalog row and the
    effort a run will use. It is offline: it reads no environment variable and
    makes no request, and every Model it returns is a deep copy.

    The provider is trimmed and matched without regard to case; an empty
    one means anthropic, and a name that is not one of Providers is refused
    (ErrUnknownProvider), whatever vendors the catalog holds.

    The model is a tier name or a model id. A string that, trimmed, is SIMPLE,
    STANDARD or ADVANCED in any case is always the tier, never an id:
    it picks the model and the effort from the provider's tier table,
    and Selection.Tier is the canonical tier. A tiers block always names a row,
    so Listed is true; a provider whose section in a parsed catalog has no tiers
    block is an error naming the provider and the tier. Anything else is an id.
    An id is only trimmed, never case-folded, and is looked up among the rows
    of the provider's own vendor, so a row of one provider is never returned for
    another. On anthropic the id goes through Lookup, which accepts an optional
    "anthropic/" prefix. An id the catalog does not list is served, not refused,
    with the provider's fallback limits, no price and Listed false.

    The effort is trimmed and folded to one of the five levels, or empty for
    none (ErrUnknownEffort otherwise). Selection.Effort is the explicit effort,
    else the tier's, else empty. It is reported as asked: Select neither filters
    nor clamps it against Model.Efforts, which is the provider's reading.

    The inputs are checked in the order provider, model, effort, and the first
    that fails is the error returned, with the zero Selection.

func (c *Catalog) Vendors() []string
    Vendors lists known vendor ids in sorted order.

func (c *Catalog) Version() string
    Version is the catalog document's own version, which moves independently of
    the SDK's (REQ-CAT-01).

type ParseError struct {
	Path   string // "vendors.anthropic.models.claude-opus-4-5.cost.input", or "" for whole-file failures
	Reason string
}
    ParseError names the exact row that failed validation. A catalog is edited
    by hand during the REQ-CAT-06 regeneration ritual, so "corrupt" without a
    path is a message that costs an hour.

func (e *ParseError) Error() string
    Error names the failing path and the reason.

func (e *ParseError) Is(target error) bool
    Is reports ErrCorruptCatalog so callers can classify without type-asserting.

type Selection struct {
	// Provider is the canonical provider name: one of Providers().
	Provider string
	// Tier is the canonical tier when the model string named one, else "".
	Tier Tier
	// Model is a deep copy of the catalog row, or the provider's fallback
	// descriptor for an id the catalog does not list. Model.ID is the id the
	// vendor will receive.
	Model core.Model
	// Effort is the effort to request: the explicit one, else the tier's, else
	// "". Whether it is sent, and in what form, is the provider's reading of
	// Model.Efforts, as on Anthropic today; Select never clamps it.
	Effort core.Effort
	// Listed reports whether Model is a row of the provider's vendor section.
	Listed bool
}
    Selection is what Select resolves a (provider, model, effort) triple to.

func Select(provider, model string, effort core.Effort) (Selection, error)
    Select resolves a (provider, model, effort) triple against the embedded
    catalog; see (*Catalog).Select.

type Tier string
    Tier is a model preset: a name that picks a model id and an effort for the
    chosen provider from the catalog's tier table.

const (
	TierSimple   Tier = "SIMPLE"
	TierStandard Tier = "STANDARD"
	TierAdvanced Tier = "ADVANCED"
)
    The three tiers. The table is fixed per release; an embedder that wants
    another mapping names the model and the effort directly.
